# PLFM

Conferences, workshops, schools, events, and opportunities for the programming languages and formal methods community, collected in one place. It is an open source repository maintained by [Bhumika Mittal](https://bhumikamittal.in/).

## Contributing

To suggest a conference, workshop, event, or school, email <bhumikamittal@gatech.edu> with a link to the official page.

Note: Inclusion here is not an endorsement, and dates should always be confirmed against the official page before you rely on them.
